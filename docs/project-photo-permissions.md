# Project Photo Permission Policy

Think Green site photos must be approved before they are published in portfolio, service, or landing page content.

## Publishing Rules

- Use homeowner-approved project photos, company-owned photos, or clearly representative planning visuals.
- Do not publish homeowner names, street addresses, license plates, gate codes, visible mail, children, private documents, or security system details.
- Keep captions focused on project scope, materials, and region unless written permission allows more detail.
- If a homeowner asks for a photo to be removed or anonymized, remove it from public pages first, then clean up derivative crops and compressed assets.
- Store permission notes with the source image file name, publishing date, and approved usage area.

## Before Adding A New Photo

1. Confirm the image source and usage permission.
2. Check the image for private details at full size.
3. Use an anonymized caption unless a specific testimonial or project story is approved.
4. Add or update the permission note before deploying.
